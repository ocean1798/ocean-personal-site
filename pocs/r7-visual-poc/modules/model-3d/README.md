# R7 M1 · ocean 连写软管 3D 首屏

入口为 `/modules/model-3d/`。当前版本验证全屏深靛蓝作品集首屏、顶部三栏身份信息、原创小写连写 `ocean` 软管模型、底部英文产品宣言、轻微整体视差和 0—360px 可逆旋转；不包含贴纸或鼠标局部形变。

`ocean-wordmark.glb` 由 `scripts/generate-model-3d.mjs` 从一条原创连续中心线生成。o、c、e、a、n 的内孔与开口通过中心线节奏区分，连接处不再切分几何；GLB 只提供一个 `OCEAN` 命名网格，整词共享同一组 TubeGeometry 法线，仅首尾带圆帽。所有笔画使用正圆截面，不使用字体轮廓或参考站字形路径。

1280×720 基准下，静态路径目标包围盒约为 `x=270—1135`、`y=190—510`，圆管直径为 60px、纵深约 70px。动态模型以 1280×720 为参考按相机宽高比统一缩放，并在 resize 时把中心保持在约 `50vh`；窄高视口不会沿用桌面固定缩放。宣言在宽视口位于约 `57vh`，宽高比小于 1.4 且高度超过 900px 时下移至约 `75vh`。透明 AVIF/WebP 海报同步 50vh 中心，页面背景、网格、三栏文字和宣言由 DOM/CSS 提供。

运行时使用 `MeshPhysicalMaterial`、`RoomEnvironment` 与 `PMREMGenerator` 表现深蓝透明软凝胶，材质为 `#3439D1` 正面、`#232078` 内部、`#090D43` 阴影。环境反射被压低，并只用一盏宽白主柔光形成连续高光，避免金属气球式碎亮面。没有描边、右侧矩形舞台或斜向装饰带。

桌面默认加载增强态；`prefers-reduced-motion` 或静态视口默认只显示海报。用户仍可明确点击“开启 3D”加载模型，开启后按钮变为“静态阅读”。完整模块验证运行 `npm run verify:model-3d`。
