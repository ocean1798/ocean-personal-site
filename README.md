# Ocean 个人网站

这是 Ocean 的个人网站。网站先让普通访客看懂嘉立创 EDA
如何参与真实电子产品的设计，再通过差分对雷达和 FPC
工坊展示 Ocean 把具体问题做成工具的方法。

## 页面

- `/`：首页，介绍 Ocean、嘉立创 EDA 主案例与两项个人工具。
- `/work`：工作页，展开团队产品职责和两项个人工具的完整过程。
- `/about`：关于页，介绍经历视角、做事方式与个人兴趣。
- 全站右下角：Ocean 的 Dify 聊天助手，点击后展开。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

运行测试：

```bash
npm test
npm run lint
```

## 项目内容

- 网站使用的图片：`public/images/`
- 页面与组件：`app/`
- 自动化测试：`tests/`

首页六步故事使用 HTML 与 CSS 绘制品牌中立的通用设备示意。公开功能截图保存在仓库中，不从第三方页面热链；截图只用于说明公开功能，不代表下载量、版本、评分或其他动态数据。

公开仓库只发布网站运行所需的源码、静态素材、测试和构建配置，不应包含个人简历原稿、内部项目资料、本机工作区记录或任何私密配置。

## 聊天助手

聊天入口使用 Dify 官方网页嵌入脚本。代码中的 Dify embed token
是浏览器加载聊天应用所需的前端公开标识，不是服务端密钥；不要在仓库中加入
Dify 管理后台密钥、模型供应商密钥或其他私密配置。聊天内容会由 Dify
及其连接的模型服务处理，请勿在聊天中输入个人隐私、公司资料、账号凭证或其他敏感信息。
